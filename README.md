Remote Operations Model
Njure Tech is built around a remote-first operating architecture.
Instead of requiring every operational function to be located inside a traditional office, teams can be distributed across locations while operating through standardized processes, client-controlled systems, security controls, and digital collaboration tools.
Operating principles
Remote by default
Operations are designed to function without dependence on a centralized physical office.
Client-budget aligned
Service structures are designed around the client's available operational budget and requirements.
Technology assisted
Digital systems and automation can be incorporated into repetitive operational workflows.
Process driven
Work is organized around documented workflows, measurable queues, quality checks, and escalation procedures.
Scalable
Operational capacity can expand or contract according to project requirements.
Zero-Cut Model
Njure Tech's operating concept is based on a zero-agency-cut model.
The objective is to minimize unnecessary intermediary layers and create a structure in which project economics can be shared more directly with the remote specialists participating in delivery.
The exact commercial structure, compensation model, and project terms may vary according to the engagement.

Getting Started
Prerequisites
Install:
Node.js
npm or Bun
Required environment variables
Clone the repository
git clone https://github.com/neerejsuresan-njuretech/Njure-tech.git
cd Njure-tech
Install dependencies
Using npm:
npm install
Or using Bun:
bun install
Configure environment variables
Create your environment configuration from the example file:
cp .env.example .env
Add the required values to .env.
Never commit production credentials, API keys, private tokens, or service-account credentials to the repository.
Development
Start the development environment:
npm run dev
Or:
bun run dev
Production Build
Build the application:
npm run build
Preview the production build:
npm run preview
Type Checking
Run the project's TypeScript validation:
npm run lint
Cleaning the Build
npm run clean
Environment Variables
Environment configuration is intentionally separated from the source code.
Use:
.env.example
as the reference for required configuration.
Production credentials should always be stored securely through the deployment environment or appropriate secret-management system.
Deployment
Njure Tech can be deployed using a suitable Node.js-compatible hosting environment.
Before deploying to production:
Configure environment variables.
Install production dependencies.
Run the production build.
Validate application routes.
Verify API and database connectivity.
Verify authentication and authorization.
Confirm that secrets are not exposed to the client.
Test SEO metadata and canonical URLs.
Verify HTTPS.
Test the production domain.
